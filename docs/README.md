# Documentação

- `especificacao/`: Documento de Especificação do Projeto Integrador (versão final em PDF e fonte)
- `requisitos/`: requisitos funcionais e não funcionais, regras de negócio e critérios de aceite
- `design/`: logo, paleta e capturas das telas (arquivo completo no Figma, link no README principal)

Regras de negócio principais:
- Preço com margem sobre o custo: `P = (custo × (1 + m) + taxa fixa) / (1 − comissão − imposto)`
- Preço com margem sobre o preço: `P = (custo + taxa fixa) / (1 − comissão − imposto − m)`
